# The Hanger 51

The Hanger 51 is a beginner-built first-person aviation game focused on aircraft interaction, maintenance, wear, repair, and eventually flight.

## Current milestone

Build a small, reliable first-person movement prototype before adding aircraft or maintenance systems.

## Development baseline

- Unity 6.3 LTS
- PC first
- Universal Render Pipeline when the visual pipeline is configured
- Unity Input System preferred
- GitHub feature branches and small, testable changes

## Repository status

The repository has been initialized. The first playable foundation will add a generated movement test area, a basic first-person controller, and setup documentation.
